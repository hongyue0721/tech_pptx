# 安全、隐私和成本底线

这是受保护的单团队演示，不是已完成多租户隔离的商业服务。公开共享一个Basic Auth账号并不产生教师之间的数据隔离；演示仅使用本包自编材料。

## 文件和解析

单文件20MiB、单项目最多5份/100MiB/200物理页/500000抽取字符，均为本项目产品限额而非底层库保证。HTTP层先限流/长度，解析子进程另设超时、内存与输出上限；压缩PDF小文件也可能有高解析成本。

忽略用户文件名作路径，服务器生成ID，在受控目录内resolve并检查边界；拒绝符号链接逃逸、绝对路径、`..`。验证PDF结构，不只扩展名/MIME。加密文件拒绝，不解密码；空白和扫描型返回明确错误。混合文件逐页告警，不声称没文本的页已读完。

PDF JS、附件、链接不执行、不递归下载；不把解析器警告当正文。文档抽取也有排序/表格/公式错误，教师应预览摘要，P0不承诺理解图表与数学公式。

## 模型与注入

模型只有输入资料片段、输出受约束JSON的权限；不能直接访问文件系统、Shell、网络、SQLite、API Key。引用ID由服务器白名单核对。输出路径、URL、工具命令均不是LLM可控字段。

资料内角色声明/提示语一律是不可信数据。分隔标记与提示说明只是附加措施，真正边界是无执行权限、严格Schema、项目限定检索、引用定位、语义核验和教师应用。提示词注入防护测试失败不能靠隐藏该资料解决。

APP endpoint由部署配置固定，教师不能输入任意BaseURL；拒绝将模型返回URL自动抓取。renderer不接受任意远程资源、任意SVG脚本或未经批准的文件路径。模型文本在浏览器转义。

## 云处理与日志

不进行Web检索≠整个产品离线。云LLM将接收课程要求、被选资料片段、待核验的文本；创建页说明并取得确认。公网只使用有权上传的材料；不承诺第三方供应商零保留或训练排除，除非其合同/设置可验证。

APP Key仅后端环境；DEV Key在开发工具本地。无VITE_*密钥、无响应回传、无Git提交、无截图泄漏。故障日志默认记录request_id/job_id/stage/版本/hash/长度/退出码，不记录全文与认证头。需要保留证据的原始响应只能在私人目录，设置到期清理。

## 服务与作业

本地只监听127.0.0.1。演示公网入口HTTPS、认证和请求限流，后端端口不对公网。使用Basic Auth时浏览器可能自动带认证，故变更接口仍要求同源Origin/Fetch Metadata校验与CSRF保护；不能只靠CORS。上传无Origin的非浏览器客户端需独立受控允许策略。

一次只有一个活动写任务/项目；进程重启将活动job标interrupted，不自动重新调用模型烧钱。所有状态变更接口幂等；取消是尽力中止，已发送供应商请求可能仍计费，不承诺退款。

预设最多24次实际模型请求/作业、并发不超过2、作业墙钟上限和输入输出token上限；负责人设每日费用预算。供应商未返回usage时记录unknown，不记0。没有费率依据就只报告token与请求数，不虚构人民币成本。

## 公开和清理

提交白名单只含源码、样例配置、原创资料和脱敏证据；真实data目录、.env、node_modules、下载缓存、私有会话不公开。项目删除需确认和无活动任务，删除原件/切块/版本/产物/日志中的项目内容；备份保留策略另行披露。

本包工具与业务未来测试都不构成安全认证。公开运行前必须人工检查端口、认证、路径处理、日志和Key；发现漏洞先关公网，不为保演示继续暴露。
