# PRD｜资料约束型教师课件助手

## 1. 目标与非目标

用户：需要把已有教学材料组织成短课件的高校教师。场景：一次课，而不是全校教学管理。产品承诺：可追溯来源、可确认修改、可编辑交付。不能承诺“无幻觉”“自动判断教学质量”“所有PPT完美兼容”或“整套系统离线”。

默认禁止外部Web检索。模型推理可调用经授权的云API，因此部分相关材料片段会发送给提供商；页面要明确说明。

## 2. P0用户旅程

创建项目：填写课题（必填）、对象、课时、教学目标，添加1—5个文本型PDF。客户端限制只改善体验，后端重复校验。

资料确认：显示文件、物理页数、解析质量、忽略/无法提取的页。老师确认允许使用这些材料进行推理。禁止隐式OCR、静默丢页或把缺文本必然归因于扫描。

大纲确认：先生成最多12页的可编辑大纲与资料覆盖提示；老师可改标题、排序和删减需求。目标45分钟不强行对应固定页数；默认8页只是Demo设置。

生成：按确认大纲逐页检索、生成事实、验证引用及语义，再生成DeckSpec和派生产物。缺资料的目标显示缺口；不以模型常识悄悄填平。

编辑：选页后请求精简、重新解释或拆页。生成候选变更和摘要；老师点“应用”才更新当前版本。排序用确定性操作，不耗模型。以“撤销上一次”生成恢复版本，不破坏历史。

交付：显示当前版本的预览类型、来源核验情况；按明确版本导出PPTX。真实打开并编辑文本框的验收不可省略。

## 3. 功能需求

| 编号 | 要求 | 验收 |
|---|---|---|
| FR-01 | 项目创建及刷新恢复 | 刷新后通过后端项目ID恢复，不丢当前版本 |
| FR-02 | 文本PDF接收、页码保留 | 主讲义8页均可提取；不混淆物理页/印刷页 |
| FR-03 | 任务内检索和覆盖 | 每个教学目标独立查询，不拿一次全局TopK写整套课件 |
| FR-04 | 教师确认大纲 | 未确认大纲不能进入正式生成 |
| FR-05 | 来源与语义校验 | 错引用、假引用、资料不足有不同状态 |
| FR-06 | 固定四类页面 | title/concept/two_column/process_example，无自由坐标模型输出 |
| FR-07 | 候选修改与应用 | 未应用的候选不改变正式课件 |
| FR-08 | 不可变版本与恢复 | 恢复产生新版本；引用和导出不串版 |
| FR-09 | 版本化PPTX | 页面数量正确，文本可编辑，实际Office验收 |
| FR-10 | 异步任务与失败恢复 | 刷新仍可查询；重启不假装任务仍运行 |
| FR-11 | 原创Skill复用核心 | CodeArts中真实调用并留记录，不只是装饰性入口 |
| FR-12 | 隐私与演示防护 | Key仅后端；明确资料外发；非授权请求不可读项目 |

## 4. P1与明确排除

P1只允许：同版高保真页图、自动视觉复核、追加材料后的全量再核验、增加一种已定义编辑意图。加入P1前所有P0通过。

不做旧PPTX导入、OCR、Word、扫描教材、外部图片搜索、复杂公式/电路图重建、任意图表、动画设计、拖拽对象、多人协同、公开多租户、实时WebSocket、MCP服务器、向量数据库。

## 5. 输入/规模限制（工程预算，不是官方数值）

单文件20MiB，最多5个，总文件100MiB，合计200个物理页；解析后项目正文最多500,000字符，超过给明确错误。默认材料先采用随包12页，200页只做资源边界测试，不宣传其性能已保证。

课时10—120分钟；生成目标4—12页，修改后最多16页。默认8页。标题最多40字符；单事实文字上限160字符；单页事实建议2—4条、最多6条。超限先拆页/压缩，不无限缩小字号。

## 6. 成功标准与产品验证

至少三轮真实模型黄金链路成功，记录模型版本、输入、用时、人工改动；至少一套变体和资料不足案例；核心知识引用位置100%可解析只是结构底线，不等同内容正确率100%。发布前人工审阅Demo全部事实。

请一位愿意配合的教师或助教按相同输入完成试用，记录最需要改的地方和实际耗时。没有真实试用时只能写“拟服务教师”，不能编造使用人数、效率提升和商业订单。所有指标是项目验收要求而非比赛分数预测。
