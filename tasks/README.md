# 施工任务板

所有任务初始PLANNED，按依赖执行；T00涉及负责人决策，T01/T02是技术准入。T03以后只允许一名Builder占用当前工作分支；Reviewer独立看diff。每项完成更新process并填真实evidence，不能仅把status改为DONE。

- **T00 / M0 资格、账号、授权和预算**：依赖 无。验收：确认学校窗口和真实队员分工；码道席位/自定义模型权限记录；外发材料/API/云预算由负责人决定；导出器第三方授权门禁记录。
- **T01 / M0 码道开发模型与Skill工具探针**：依赖 T00。验收：8项DEV smoke记录；最小Skill被加载且真实读写/运行测试；失败测试真实修复；会话导出脱敏索引。
- **T02 / M0 AnyUI/PDF/导出器最小链**：依赖 T00。验收：AnyUI实际安装生产构建；pypdf中文8页抽取；已授权Exporter生成可编辑PPTX；负责人目标Office打开；未打开标NOT_RUN。
- **T03 / M1 Schema/API与工程骨架**：依赖 T01, T02。验收：类型与契约对齐；基础项目创建/获取/错误响应；前端本地路由骨架；契约测试可运行。
- **T04 / M1 SQLite任务、幂等与版本仓库**：依赖 T03。验收：单Worker/项目锁；幂等同键与冲突；重启interrupted；原子文件与数据库指针一致。
- **T05 / M1 PDF导入、规范化与切块**：依赖 T04。验收：正常/扫描/空/加密/损坏测试；页码/偏移/hash正确；限额/跨路径拒绝；每页质量警告。
- **T06 / M1 检索、覆盖与证据定位**：依赖 T05。验收：逐目标BM25检索；同项目同revision；quote唯一子串与精确偏移；改名/变体不特判。
- **T07 / M2 APP模型Adapter与预算**：依赖 T03。验收：实际协议smoke；typed JSON/schema校验；429/timeout/401重试策略；预算/usageunknown/取消。
- **T08 / M2 大纲生成和教师确认**：依赖 T06, T07。验收：coverage缺口显示；draft/confirmed/stale；确认受支持目标；未确认不能生成。
- **T09 / M2 候选课件、语义核验和提交**：依赖 T08, T04。验收：模型生成候选Deck；独立语义核验；假引用/冲突/缺证据阻塞；教师应用才更新version。
- **T10 / M2 固定模板渲染和版本导出**：依赖 T09, T02。验收：四布局固定；真实editable PPTX；artifact固定version；结构预览诚实降级。
- **T11 / M3 Vue教师创建与工作区**：依赖 T03, T08, T10。验收：多PDF队列；大纲确认/候选应用；状态轮询/刷新/错误；来源Drawer/下载。
- **T12 / M3 受限编辑、拆页与恢复**：依赖 T09。验收：replace/split/reorder受限patch；非目标hash不变；claim集合保留；restore新version且冲突拒绝。
- **T13 / M3 原创Skill共享core落地**：依赖 T09, T10, T12。验收：目标CLI真实实现；独立data-dir锁；码道Skill黄金链实际运行；公开目录和安装说明不带大依赖。
- **T14 / M4 全链回归和反例验收**：依赖 T11, T12, T13。验收：3次APP_LIVE完整流程；变体/资料不足/冲突/注入；导出Office修改保存；截图与报告区分NOT_RUN。
- **T15 / M4 保护性云部署和干净复现**：依赖 T14。验收：负责人批准公网/费用；HTTPS/认证/Origin与限流；重启恢复；干净环境安装复测。
- **T16 / M5 比赛交付、视频和开源**：依赖 T15。验收：实际技能AtomGit发布由负责人确认；脱敏码道记录/真实贡献；演示视频与完整局限；校内提交成功证据。
